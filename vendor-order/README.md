# 공장 주문서 (TJ300 양식)

업체가 준 엑셀 주문서 원본 두 개. **노션 「장부」의 주문서 DB 두 개와 1:1로 맞춘다.**

| 파일 | 대응 노션 DB | 왼소매 이니셜 |
|---|---|---|
| `TJ300_영어필기체.xlsx` | 학잠 주문서 ( 영어 필기체 ) | 라틴문자, **필기체** |
| `TJ300_한글한자특수문자.xlsx` | 학잠주문서(한글 한자 특수문자) | 한글·한자·특수문자·없음, **고딕체** |

업체 규칙(양식 60~65행)상 **필기체는 전원 영문일 때만** 가능하다. 한 명이라도 한글/한자/특수문자가 섞이면 그 주문서는 통째로 고딕체가 된다. 그래서 파일이 둘로 갈려 있다.

## 갱신

입금이 확인되면 노션 주문서 DB에 행을 넣고, 그 DB 내용을 그대로 엑셀에 반영한다.

```sh
python3 vendor-order/fill.py vendor-order/TJ300_영어필기체.xlsx people.json
```

`people.json` = `[{"email": "korolukvika3", "size": "M", "initial": "lofy"}, ...]`
(email 은 @ 앞부분만 — 업체 양식이 그렇게 쓰여 있다.)

정렬은 스크립트가 한다 — 업체 요구대로 S·M·L·XL·2XL·3XL·4XL·5XL 순. 22~23행 사이즈별 수량도 같이 갱신된다.

`fill.py` 는 openpyxl 을 쓰지 않는다. 이 양식에는 vml·드로잉·이미지가 들어 있어서 openpyxl 로 열었다 저장하면 그게 날아간다. `xl/worksheets/sheet1.xml` 과 `xl/sharedStrings.xml` 만 고치고 나머지 zip 엔트리는 바이트 그대로 복사한다. 행을 다시 쓸 때 열 순서와 `s=`(스타일) 속성을 보존한다.
